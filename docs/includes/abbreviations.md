*[Neurons]: Computational units computing weighted sums, biases, and activation functions.
*[Weights]: The learned numerical parameters scaling inputs inside a neural network.
*[Bias]: The learned numerical offset added to a neuron's weighted sum.
*[Activation Function]: A non-linear function applied to a neuron's output allowing networks to learn non-linear patterns.
*[Activation Functions]: Non-linear functions applied to neuron outputs allowing networks to learn complex patterns.
*[ReLU]: Rectified Linear Unit activation function; replaces negative values with zero.
*[Tokenization]: Splitting raw text into smaller chunks (tokens) that map to vocabulary indices.
*[Tokens]: The discrete text fragments (words, sub-words, characters) processed by language models.
*[Embedding]: A dense vector representing the semantic meaning of a token, word, or text snippet.
*[Embeddings]: Dense vectors representing semantic meaning where similarity corresponds to distance.
*[Vector Space]: The high-dimensional geometric space where embeddings live.
*[Transformer]: The neural network architecture behind modern LLMs utilizing self-attention.
*[Transformers]: Neural network architectures behind modern LLMs utilizing self-attention.
*[Attention]: The mechanism that dynamically weights contextual relationships between tokens.
*[Self-Attention]: An attention mechanism where tokens in a sequence attend to all other tokens in the same sequence.
*[Multi-Head Attention]: Running multiple attention mechanisms in parallel to capture distinct relationships.
*[Softmax]: An exponentiated normalization function converting raw scores into probabilities that sum to 1.
*[Next-Token Prediction]: The fundamental autoregressive loop generating one token at a time based on preceding context.
*[Logits]: Unnormalized numerical scores produced by a neural network layer before applying softmax.
*[Temperature]: A scaling factor applied to logits before softmax controlling prediction randomness.
*[System Prompt]: Initial instructions defining an LLM's persona, constraints, and operational guidelines.
*[Context Window]: The maximum number of tokens a model can ingest and process in a single invocation.
*[Prompt Pipeline]: The programmatic process of gathering context, formatting templates, and feeding an LLM.
*[Hallucination]: When a generative model produces plausible-sounding but factually incorrect outputs.
